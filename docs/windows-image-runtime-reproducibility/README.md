# Authenticated Windows image runtime build

This candidate recipe targets Windows x64 CPU and CUDA 12.4/SM86. It uses the pinned stable-diffusion.cpp 07a85c74 source and ggml gitlink, two authenticated HTTP routes, exact-round-trip compressed tokenizer tables, baseline CPU instructions and OpenMP off. Windows CUDA uses FlashAttention off and consistent dynamic MSVC runtime flags. Builds do not certify paired execution or public installation.

Use Python 3.12.2 with zlib 1.3.1, installed Visual Studio 2019 Build Tools 14.29.30133 (compiler 19.29.30154), and neutral build directories. No driver is bundled or installed by these helpers. Source/tool preparation verifies the committed file inventories; unknown source files, links, changed bytes and personal paths are refused. CMake 3.31.8 and NVIDIA CUDA 12.4.1 component URLs, archive hashes, selected per-file hashes and original licences are committed alongside the recipe. One unused optional CMake module is omitted and recorded by path hash.

```powershell
python -B docs/windows-image-runtime-reproducibility/prepare-source.py --root C:/ExcessBuilds/image-source
python -B docs/windows-image-runtime-reproducibility/prepare-tools.py --root C:/ExcessBuilds/image-tools --cuda
python -B docs/windows-image-runtime-reproducibility/build.py --source C:/ExcessBuilds/image-source/sd --cmake-root C:/ExcessBuilds/image-tools/cmake --vcvars "C:/Program Files (x86)/Microsoft Visual Studio/2019/BuildTools/VC/Auxiliary/Build/vcvars64.bat" --build C:/ExcessBuilds/image-cpu-a --backend cpu
python -B docs/windows-image-runtime-reproducibility/build.py --source C:/ExcessBuilds/image-source/sd --cmake-root C:/ExcessBuilds/image-tools/cmake --vcvars "C:/Program Files (x86)/Microsoft Visual Studio/2019/BuildTools/VC/Auxiliary/Build/vcvars64.bat" --build C:/ExcessBuilds/image-cuda-a --backend cuda --cuda-root C:/ExcessBuilds/image-tools/cuda-12.4
```
