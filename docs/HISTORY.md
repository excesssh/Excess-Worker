# Reconstruction history

The reconstruction contains 47 source commits; one related historical change was consolidated into an existing public checkpoint. The selected first-parent worker, adapter, and protocol source dates are 14-27 September 2026, and the extracted source states preserve those dates. New security work and standalone documentation were added on 5 October 2026.

The reconstruction selected apps/worker, packages/adapters, packages/protocol, their required workspace/build files, and focused tests whose dependencies fit that source boundary. Changes from the same topic and calendar day may be represented by one final checkpoint state. No private source revision identifiers are included here.

The extraction is not the full EXCESS product history. It omits the web application, coordinator implementation, database and migrations, custody, settlement, credentials for live services, deployment configuration, and tests that require those private-stack components. The separately operated coordinator and production services are not included or provided by this repository.

The historical source range ends before this documentation work. It should not be read as a current product release timeline or proof that any hosted service was available.
